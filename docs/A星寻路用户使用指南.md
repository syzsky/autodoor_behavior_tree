# A* 寻路插件使用指南：地图编辑与自动化流程创建

> 版本：v1.0 | 日期：2026-07-31
> 适用版本：AutoDoor Behavior Tree v2.0+

---

## 一、快速入门

### 1.1 三分钟快速上手

#### 步骤 1：加载 A* 寻路插件

1. 打开应用，点击「🔌 插件管理」Tab
2. 找到「A星寻路」插件
3. 点击「启动」按钮，状态变为绿色 ●

#### 步骤 2：绘制你的第一张地图

1. 切换到「🌲 行为树编辑器」
2. 从左侧「插件节点」面板拖拽 **「地图编辑器」** 节点到画布
3. 双击该节点打开地图编辑器窗口
4. 使用鼠标在网格上点击绘制地图（见下图）
5. 点击「保存」将地图存入黑板

#### 步骤 3：创建第一个寻路行为

1. 拖拽 **「A* 寻路」** 节点到画布
2. 配置起点坐标 (0,0) 和终点坐标 (10,10)
3. 点击「运行」按钮执行行为树
4. 观察结果：屏幕上出现一个沿路径移动的动画

- 双击任何 A* 相关节点

### 2.3 绘制地图的四种方式

#### 方式 1：手动绘制

**适用场景**：小型地图、精确控制

1. 选择「绘制」工具
2. 在网格上**单击**标记障碍
3. **拖拽**可连续绘制
4. 选择「擦除」工具可以清除障碍
5. 选择「起点」「终点」工具设置路径端点

#### 方式 2：从图片导入

**适用场景**：从游戏截图、平面图转换

1. 点击「导入图片」按钮
2. 选择图片文件（支持 PNG/JPG/BMP）
3. 在弹出的对话框中设置参数：
   - **阈值**：二值化阈值（0-255），自动区分可通行/障碍
   - **网格大小**：每个网格对应的像素数
   - **反转**：如果黑色代表可通行则勾选
4. 点击「预览」查看效果
5. 调整参数后点击「确认导入」

#### 方式 3：从 JSON 加载

**适用场景**：批量导入、版本管理

1. 点击「导入 JSON」按钮
2. 粘贴或选择 JSON 文件：
```json
{
    "width": 20,
    "height": 20,
    "obstacles": [
        {"x": 5, "y": 5},
        {"x": 5, "y": 6},
        {"x": 5, "y": 7},
        {"x": 10, "y": 10},
        {"x": 10, "y": 11}
    ],
    "start": {"x": 0, "y": 0},
    "goal": {"x": 19, "y": 19},
    "allow_diagonal": true
}
```
3. 点击「加载」导入地图

#### 方式 4：屏幕实时捕获

**适用场景**：有小地图的游戏

1. 切换到「屏幕捕获」模式
2. 在屏幕上拖拽选择小地图区域
3. 设置参数：
   - **捕获频率**：1-5 次/秒
   - **自动更新**：勾选后地图实时更新
4. 开始捕获，地图自动更新

### 2.4 地图高级操作

#### 填充工具

1. 选择「填充」工具
2. 在网格上点击某个区域
3. 选择填充颜色（障碍/可通行）
4. 该区域所有连通格子被填充

#### 随机生成

1. 点击「随机」按钮
2. 设置参数：
   - **宽度/高度**：地图尺寸
   - **障碍密度**：0-100%，默认 20%
   - **种子**：可选，固定随机结果
3. 点击「生成」创建随机地图

#### 地图编辑快捷键

| 操作 | 快捷键 |
|------|--------|
| 绘制障碍 | `D` 键 |
| 擦除障碍 | `E` 键 |
| 设置起点 | `S` 键 |
| 设置终点 | `G` 键 |
| 填充 | `F` 键 |
| 清空地图 | `Ctrl + Delete` |
| 保存地图 | `Ctrl + S` |
| 撤销操作 | `Ctrl + Z` |
| 重做操作 | `Ctrl + Y` |

### 2.5 保存与加载地图

#### 保存地图

1. 点击「保存」按钮或按 `Ctrl + S`
2. 输入地图名称（如 "forest_map"）
3. 地图保存到项目的 `maps/` 目录

地图存储位置：
```
your_project/
├── maps/
│   ├── forest_map.json
│   ├── dungeon_level1.json
│   └── city_map.json
```

#### 加载地图

1. 点击「加载」按钮
2. 从列表中选择已保存的地图
3. 或直接拖拽 `.json` 文件到编辑器

#### 导出地图

1. 点击「导出」按钮
2. 选择导出格式：
   - **JSON**：包含完整地图数据
   - **PNG**：导出为图片
   - **CSV**：导出为二维数组
3. 选择保存位置

## 三、创建自动化流程

### 3.1 行为树结构设计

#### 基础结构模板

```
┌─────────────────────────────────────────────────────────────┐
│                        StartNode                            │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              SequenceNode（顺序执行）                │   │
│  │                                                     │   │
│  │  ① 加载地图  ──►  ② 规划路径  ──►  ③ 执行路径      │   │
│  │                                                     │   │
│  │     地图节点         A* 寻路节点      路径执行节点    │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 完整自动化结构

```
┌─────────────────────────────────────────────────────────────┐
│                        StartNode                            │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              SequenceNode（主循环）                  │   │
│  │                                                     │   │
│  │  ① 捕获屏幕  ──►  ② 识别目标  ──►  ③ A* 规划       │   │
│  │     截图节点         识别节点         寻路节点       │   │
│  │                                                     │   │
│  │  ④ 检查路径  ──►  ⑤ 执行移动  ──►  ⑥ 到达后动作    │   │
│  │     条件节点         执行节点         动作节点       │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  🔁 循环执行（直到手动停止或满足退出条件）                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 可用节点列表

#### 地图类节点

| 节点名 | 功能 | 配置项 |
|--------|------|--------|
| **加载地图** | 从文件加载地图 | 地图路径、存为黑板键名 |
| **创建地图** | 创建空地图 | 宽度、高度、存为黑板键名 |
| **添加障碍** | 添加单个障碍物 | 地图键名、X 坐标、Y 坐标 |
| **移除障碍** | 移除单个障碍物 | 地图键名、X 坐标、Y 坐标 |
| **从图片导入** | 从截图创建地图 | 图片路径、阈值、网格大小 |

#### 寻路类节点

| 节点名 | 功能 | 配置项 |
|--------|------|--------|
| **A* 寻路** | 规划单段路径 | 地图键名、起点、终点、启发式函数 |
| **多点寻路** | 规划多段路径 | 地图键名、航点列表、启发式函数 |
| **路径可视化** | 显示路径预览 | 地图键名、路径键名、显示模式 |

#### 执行类节点

| 节点名 | 功能 | 配置项 |
|--------|------|--------|
| **执行路径** | 按路径移动 | 路径键名、步间隔、移动速度 |
| **单步执行** | 只执行一步 | 路径键名、步数 |
| **条件导航** | 条件触发导航 | 条件表达式、目标点 |

#### 感知类节点

| 节点名 | 功能 | 配置项 |
|--------|------|--------|
| **屏幕截图** | 截取游戏画面 | 区域、频率 |
| **元素识别** | 识别屏幕元素 | 模板路径、置信度、搜索区域 |
| **地图更新** | 从截图更新地图 | 截图键名、地图键名 |

### 4.1 案例一：游戏角色自动巡逻

#### 场景描述

3. 用「绘制」工具画出障碍物
4. 用「填充」工具快速填充障碍区域
5. 点击「保存」，命名为 `patrol_route`

**Step 2：创建行为树**
1. 从左侧面板拖拽以下节点到画布：
   - `[StartNode]` → `[SequenceNode]` → `[加载地图]` → `[多点寻路]` → `[循环执行路径]`
2. 连接节点

**Step 3：配置节点**
- **加载地图节点**

  - 存储键名：`patrol_map`

  - 地图键名：`patrol_map`

**Step 1：准备 Excel 数据**
创建 `waypoints.xlsx`：

```
StartNode
  ├── Excel 读取
  │   文件: waypoints.xlsx
  │   输出键: waypoints
  ├── 代码节点（解析航点）
  │   将 Excel 数据转为路径坐标列表
  ├── 加载地图
  │   地图: maps/factory.json
  │   输出键: factory_map
  ├── 多点寻路
```

```python
# 解析 Excel 航点数据
import json
```

## 五、最佳实践与技巧

### 5.1 地图设计技巧

| 技巧 | 说明 |
|------|------|
| **合理网格分辨率** | 推荐 8-16 像素/格，太小计算慢，太粗不精确 |
| **清晰的障碍物** | 保持障碍物边界清晰，避免模糊区域 |
| **合理的地图大小** | 初始建议 20×20，复杂场景可扩大到 50×50 |
| **预定义通行区域** | 用不同颜色标记可通行、障碍、危险区域 |
| **标注起点终点** | 保存时标记常用起点终点，便于快速调用 |

### 5.2 流程设计技巧

| 技巧 | 说明 |
|------|------|
| **模块化设计** | 将常用流程保存为子树模板 |
| **合理错误处理** | 添加条件节点检查关键步骤是否成功 |
| **状态同步** | 定期更新黑板中的状态数据 |
| **渐进式开发** | 先实现基础路径，再增加复杂逻辑 |
| **日志记录** | 添加日志节点记录关键步骤，便于调试 |

### 5.3 执行优化技巧

| 技巧 | 说明 |
|------|------|
| **合理步间隔** | 100-200ms 较合适，太快可能丢帧，太慢效率低 |
| **添加随机延迟** | 在基础延迟上加 ±30% 随机波动 |
| **路径平滑** | 开启路径平滑，减少抖动 |
| **批量执行** | 多段路径合并执行，减少中断 |
| **动态重规划** | 长路径分段执行，支持中途重新规划 |

### 5.4 调试技巧

| 技巧 | 说明 |
|------|------|
| **路径预览** | 使用「路径可视化」节点预览规划结果 |
| **分步执行** | 用「单步执行」逐步调试 |
| **日志输出** | 开启详细日志，观察每步执行结果 |
| **断点设置** | 在关键节点设置断点检查状态 |
| **单元测试** | 为每个流程创建测试用例 |

## 六、常见问题解答

### Q1：如何获取游戏的小地图截图？

**方法**：
1. 使用 `Windows + Shift + S` 打开系统截图工具
2. 框选小地图区域
3. 截图自动保存到剪贴板
4. 粘贴到「画图」并保存为 PNG

或者在代码节点中：
```python
import pyautogui
# 截取小地图区域
minimap = pyautogui.screenshot(region=(700, 100, 200, 200))
minimap.save("minimap_current.png")
```

### Q2：规划的路径不通怎么办？

**排查步骤**：
1. 检查地图中起点和终点是否为可通行区域
2. 使用「路径可视化」预览规划结果
3. 检查障碍物是否正确标记
4. 尝试调整启发式函数
5. 缩小地图或重新生成

### Q3：执行路径时角色不动？

**可能原因**：
1. 游戏窗口未获得焦点 → 激活游戏窗口
2. 移动速度过快 → 调低移动速度
3. 坐标映射错误 → 检查网格到屏幕的映射关系
4. 被游戏反检测机制拦截 → 添加随机偏移

### Q4：如何适配不同分辨率？

**方法 1**：使用相对坐标
```python
# 代码节点中
screen_width = pyautogui.size().width
scale = screen_width / 1920  # 以 1920 为基准

x = int(grid_x * cell_size * scale)
y = int(grid_y * cell_size * scale)
```

**方法 2**：使用百分比坐标
```python
# 地图保存时使用百分比
{
    "obstacles_percent": [
        {"x": 0.25, "y": 0.5},  # 25% 宽, 50% 高
        ...
    ]
}
```

### Q5：如何创建可复用的流程模板？

**步骤**：
1. 在画布上选中要复用的子树
2. 右键 → 「保存为模板」
3. 输入模板名称和描述
4. 在其他行为树中通过「从模板创建」快速添加

模板保存位置：
```
your_project/
├── templates/
│   ├── patrol_template.bt
│   ├── combat_template.bt
│   └── pickup_template.bt
```

### 启发式函数选择

| 场景 | 推荐函数 | 说明 |
|------|---------|------|
| 4 方向移动 | 曼哈顿距离 | `abs(x1-x2) + abs(y1-y2)` |
| 8 方向移动 | 对角距离 | `max(\|dx\|, \|dy\|)` |
| 任意方向 | 欧几里得距离 | `sqrt(dx² + dy²)` |

| ARPG | 100-200ms | 自然移动 |
